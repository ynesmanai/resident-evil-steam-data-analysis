Resident Evil & Steam: A Data-Driven Exploration

An academic data analytics project exploring the Steam gaming market and the Resident Evil franchise using Python and Power BI.

 Project Overview

This project explores the Steam gaming market and the Resident Evil franchise through game metadata and player reviews.

The analysis is divided into two parts:

- Steam Market Overview: Exploring game releases, genres, platforms, prices, and Metacritic scores.
- Resident Evil Analysis: Comparing selected games through player reviews, sentiment distribution, review volumes, and available Metacritic scores.

The objective is to transform raw data into visualizations that make it easier to explore patterns and compare games.

Tools & Technologies

- Python: Data preparation and filtering using pandas.
- Power BI: Data visualization and dashboard development.
- CSV: Data storage and exchange.

 Project Workflow

1. Prepared Steam game data for analysis.
2. Filtered a large Steam reviews dataset to extract reviews associated with Resident Evil games.
3. Processed the resulting data for use in Power BI.
4. Designed interactive dashboards to explore the Steam market and compare Resident Evil titles.
5. Analyzed review distributions and player sentiment across selected games.

 Key Figures

Based on the Resident Evil review dataset analyzed:

- 14,473 reviews collected
- 11,366 positive reviews
- 78.53% positive review rate

These figures describe the dataset used in this project and should not be interpreted as representative of every Resident Evil player.
